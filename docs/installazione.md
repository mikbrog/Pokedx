# Installazione Pokedx

Il progetto Pokedx è un'applicazione web statica che non richiede compilazione o backend dedicato.

## Prerequisiti
- Un browser web moderno (Chrome, Firefox, Edge, Safari).
- Connessione internet attiva (per il caricamento delle librerie Bootstrap via CDN e l'accesso alla PokeAPI).

## Istruzioni
1. Scarica o clona la cartella del progetto.
2. Assicurati che i file `index.html`, `pokemon.html`, `tipi.html`, `style.css` e `script.js` siano tutti nella stessa directory principale.
3. Apri il file `index.html` direttamente nel tuo browser.
4. (Opzionale) Se intendi testare il file di fallback locale, assicurati di avere un file `data.json` correttamente formattato nella root del progetto.
